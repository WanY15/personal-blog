每年都会看到各种“效率神器”推荐，我也跟风装过不少，最后发现真正留下来的就那么几个。这份清单里的工具，最短的用了两年，最长的用了五六年。它们不一定流行，但确实融进了我的日常。

## 编辑器与终端

- **VS Code**：前端开发的主力，插件只留了 ESLint、Prettier、GitLens、Error Lens 和一个用来练 Vim 键位的插件。插件装多了会卡，我把“看起来有用”的都卸了，每隔半年再清一次，三个月没用到的直接删。
- **Windows Terminal + PowerShell 7**：Windows 下最舒服的组合，分屏、标签页、自定义配色都够用。配合 oh-my-posh，命令行看起来顺眼很多。
- **WSL2**：跑构建、装一些 Linux 工具链，比在 Windows 里折腾环境省心。代价是文件系统性能，所以项目目录我会放在 WSL 内部，而不是 `/mnt/f` 下面。

## 效率小工具

- **PowerToys**：微软官方的工具箱，我最常用的是 PowerToys Run（快速启动）和 FancyZones（窗口分屏布局）。
- **Everything**：按文件名搜索快得离谱，装完之后基本没再打开过资源管理器自带的搜索。
- **Snipaste**：截图加贴图，写 bug 描述和文档时非常方便。
- **Obsidian**：本地 Markdown 笔记，双链和标签都很轻量，我的读书笔记和书单都放在里面。
- **Flow Launcher**：Windows 上的启动器，替代开始菜单；Mac 用户可以用 Raycast，挑一个顺手的就行，别两个都装。

## 浏览器与阅读

- **Edge + Vimium**：日常浏览用 Edge，主要是省内存，配上 Vimium 之后键盘翻页、开标签，几乎不用碰鼠标。
- **Feedly**：订阅了十几个技术博客和几个设计站，每天固定看二十分钟，比刷信息流安静得多。
- **网页剪藏**：看到好文章先用 Obsidian 的插件存下来，周末统一读，避免工作时被一篇长文带着跑。

## 命令行里的固定搭配

- `ripgrep`：搜代码，比 grep 快一个量级，`rg "关键词"` 已经成了肌肉记忆。
- `fd`：找文件，语法比 find 友好太多。
- `zoxide`：`z 项目名` 直接跳目录，省掉一长串 cd。
- `fzf`：模糊查找，配合命令历史和文件搜索一起用。

::tip
工具装得越多不等于效率越高。我的建议是：先记下自己每天重复三次以上的动作，再去找对应工具。反过来“先装后找用途”，最后只会收获一个塞满图标的开始菜单。
:::

## 写在最后

整理这份清单时，我发现自己留下的都是“不用想就会打开”的工具。那些需要先学半小时配置、再花时间维护的，无论评测多好，最后都逃不过被卸载的命运。所以选择工具的标准其实很朴素：它得比我原本的做法更省事，否则就不值得。

这两年我最大的变化，是开始主动做减法。桌面上只留必要的东西，浏览器标签超过十个就关掉，通知一律默认静音。工具终究是工具，它应该帮我把事情做完，然后尽快从视线里消失。
